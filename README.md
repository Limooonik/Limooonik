# Limooonik | Native Motion Engineering

**Specialized Architecture for iOS Widgets & Live Activities**

Creator of the first App Store approved library for continuous, native iOS widget animations. This architecture bridges the gap between complex UI/UX motion design and Apple's strict `WidgetKit` limitations, completely bypassing the resource constraints and memory crashes associated with Rive, Lottie, and heavy raster files.

### Core Technology
By relying entirely on pure mathematics (`Path{}`) and CoreGraphics, this native approach delivers:
* **Continuous morphing** on the Homescreen, Lockscreen, and Live Activities.
* **0% CPU usage & zero background battery drain**.
* **100% App Store compliant** (zero private APIs, completely crash-free).
