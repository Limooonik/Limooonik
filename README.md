**Full-cycle iOS Developer & Native Motion Engineer** 

Creator of the first App Store approved library for continuous, native iOS widget animations (bypassing the limitations of Rive/Lottie without memory crashes).

### 🚀 Core Expertise: Native Widget Animation
I bridge the gap between complex UI/UX motion design and Apple's strict `WidgetKit` limitations. By relying entirely on pure mathematics (`Path{}`) and CoreGraphics instead of heavy raster files, I build widget animations that deliver:
* **60fps-like continuous morphing** on the Homescreen, Lockscreen, and Live Activities.
* **0% CPU usage & zero background battery drain**.
* **100% App Store compliant** (zero private APIs, completely crash-free).
